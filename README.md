## Project: [Credit Default Risk Prediction](https://github.com/u6062992/home-credit-project)

This project demonstrates an end-to-end machine learning workflow designed to predict the likelihood of credit default. The analysis integrates multiple data sources, applies extensive feature engineering, and evaluates models using best practices for imbalanced classification.

A key focus of the project is not only model performance, but also interpretability and insight generation. The distribution of predicted default probabilities (shown below) highlights how the model differentiates between low- and high-risk applicants, providing a more nuanced understanding than a simple binary classification.

The final model, an optimized XGBoost classifier with downsampling, achieved an AUC of 0.751 on the Kaggle leaderboard. This performance reflects strong generalization and demonstrates the effectiveness of combining feature engineering, data integration, and thoughtful validation strategies.
